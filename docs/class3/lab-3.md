# 실습 3-3. 프롬프트 파일 만들기

!!! abstract "이 실습에서 할 일"
    - 자주 쓰는 요청을 **프롬프트 파일** `.github/prompts/story.prompt.md`로 저장합니다.
    - **Local** 하네스 채팅에서 `/story`로 실행해, 선택한 요구 문장을 사용자 스토리와 인수 조건으로 바꿉니다.
    - 프롬프트 파일을 커밋해 팀이 재사용할 수 있게 합니다.

    **예상 시간** 약 11분

## 프롬프트 파일이란

| 구분 | 지침 파일 (3-2) | 프롬프트 파일 (3-3) |
|---|---|---|
| 파일 | `.github/copilot-instructions.md` | `.github/prompts/이름.prompt.md` |
| 언제 쓰이나 | 모든 채팅에 **항상** 자동으로 | 내가 `/이름`으로 **부를 때만** |
| 무엇을 쓰나 | 지켜야 할 규칙 | 반복하는 작업 하나의 요청문 |

3-1에서 "결정하지 못한 것은 확인 필요로" 같은 규칙을 매번 붙여 넣었습니다. 이런 요청을 파일로 저장해 두면 `/story` 한 번으로 같은 품질의 결과를 받을 수 있습니다.

## STEP 1. prompts 폴더와 파일 만들기

1. 왼쪽 탐색기에서 `.github` 폴더를 마우스 오른쪽 버튼으로 클릭하고 **New Folder...**를 고릅니다.
2. 폴더 이름에 `prompts`를 입력하고 Enter를 누릅니다.
3. 방금 만든 `prompts` 폴더를 마우스 오른쪽 버튼으로 클릭하고 **New File...**을 고릅니다.
4. 파일 이름에 아래를 입력하고 Enter를 누릅니다.

    ```text
    story.prompt.md
    ```

확인: 탐색기에 `.github/prompts/story.prompt.md`가 보입니다.

!!! tip "명령으로 만드는 방법"
    명령 팔레트(Windows `Ctrl+Shift+P`, Mac `⇧⌘P`)에서 **Chat: New Prompt File**을 실행해도 됩니다. 이 리포지토리의 `.github/prompts` 폴더에 `story`라는 이름으로 만듭니다.

## STEP 2. 프롬프트 내용 쓰기

1. 아래 내용을 통째로 복사해 `story.prompt.md`에 붙여 넣습니다.

    ```markdown
    ---
    description: 선택한 요구 문장을 사용자 스토리와 인수 조건으로 바꾼다
    agent: ask
    ---
    아래 선택한 문장을 사용자 스토리로 바꿔 주세요.

    ${selection}

    형식:
    ### 스토리 제목
    - 스토리: <누구>로서, <무엇>을 원한다. <왜>이기 때문이다.
    - 인수 조건:
      - 확인할 수 있는 조건을 2~4개, 구체적인 시간이나 숫자 예시로 쓴다.
    - 확인 필요: 선택한 문장과 docs/ 문서에 없어서 정하지 못한 것. 없으면 "없음".

    규칙:
    - 선택한 문장과 docs/ 문서에 없는 정책은 정하지 말고 "확인 필요"에 적는다.
    - 한국어로 쓴다.
    ```

2. 저장합니다(Windows `Ctrl+S`, Mac `⌘S`).

확인: 파일 맨 위가 `---`로 시작하고, `description`과 `agent: ask` 두 줄 뒤에 다시 `---`가 있습니다.

!!! note "각 부분의 뜻"
    - 맨 위 `---` 사이를 **머리말**이라고 합니다. `description`은 `/` 목록에 보이는 설명, `agent: ask`는 Ask 역할로 실행하라는 뜻입니다(`agent`, `plan`도 쓸 수 있습니다).
    - `${selection}`은 실행할 때 **편집기에서 선택한 글**로 바뀌는 자리입니다.
    - 명령 이름은 파일 이름에서 옵니다. `story.prompt.md` → `/story`.

## STEP 3. 요구 문장 선택하기

1. 탐색기에서 `docs/00_현업요청.md`를 엽니다.
2. "바라는 점" 아래의 한 줄을 마우스로 끌어 선택합니다. 예:

    ```text
    - 예약을 취소할 수 있어야 합니다.
    ```

확인: 편집기에서 그 줄이 파랗게 선택되어 있습니다. 다음 STEP을 하는 동안 선택을 풀지 않습니다.

## STEP 4. Local 하네스에서 /story 실행하기

!!! warning "프롬프트 파일은 Local 하네스에서만 실행됩니다"
    지금까지 쓴 **Copilot** 하네스 채팅에서는 `/story`가 실행되지 않습니다. Session Target을 **Local**로 바꾼 새 채팅에서 실행합니다.

1. Chat 보기에서 **+**(**New Chat**)를 클릭합니다.
2. **Session Target** 컨트롤에서 **Local**을 고릅니다.
3. 모델이 **Auto**인지 확인합니다.
4. 입력 칸에 `/`를 입력하고, 목록에서 **story**를 고릅니다. 설명에 "선택한 요구 문장을 사용자 스토리와 인수 조건으로 바꾼다"가 보입니다.
5. Enter를 누릅니다.

확인: 선택한 "예약을 취소할 수 있어야 합니다."가 스토리 한 개와 인수 조건, "확인 필요"로 바뀌어 나옵니다. 예를 들어 "취소는 예약한 본인만 할 수 있는가", "지난 예약도 취소할 수 있는가"가 확인 필요로 나오면 잘 된 것입니다.

!!! note "화면이 조금 다를 수 있어요"
    `/`를 입력해 목록에서 고르는 대신 명령 팔레트의 **Chat: Run Prompt**로 `story`를 골라도 됩니다. Local 채팅은 VS Code 창을 닫으면 멈춥니다.

## STEP 5. 다른 문장으로 한 번 더

1. `docs/01_킥오프_회의록.md`를 엽니다.
2. "논의 내용"에서 강도윤과 최수연이 최대 예약 시간을 이야기한 두 줄을 선택합니다.
3. Local 채팅에서 다시 `/story`를 실행합니다.

확인: 최대 시간이 2시간인지 4시간인지 **정하지 않고** "확인 필요"에 들어가 있으면 됩니다. 정해 버렸다면 프롬프트 파일의 규칙 문장을 더 분명하게 고칩니다.

## STEP 6. 커밋하기

1. Session Target을 다시 **Copilot**으로 돌려 둡니다(다음 교시부터는 Copilot 하네스를 씁니다). **+**(**New Chat**) 후 Session Target에서 **Copilot**을 고르면 됩니다.
2. 소스 제어(Windows `Ctrl+Shift+G`, Mac `⌃⇧G`)를 엽니다.
3. **Changes**에 `story.prompt.md`만 있는지 확인합니다.
4. 메시지 칸에 아래를 입력하고 **Commit**, 이어서 **Sync Changes**를 누릅니다.

    ```text
    사용자 스토리 프롬프트 파일 추가
    ```

확인: github.com의 `room-practice`에서 `.github/prompts/story.prompt.md`가 보입니다.

!!! tip "팀에서 재사용하기"
    프롬프트 파일을 리포지토리에 커밋하면 이 리포지토리를 가져간 **팀원 모두**가 같은 `/story`를 씁니다. 5교시 팀 실습에서 템플릿으로 만든 팀 리포지토리에도 같은 방법으로 넣을 수 있습니다.

    프롬프트 파일은 Local 하네스에서만 실행되므로, Copilot 하네스 같은 다른 하네스에서도 재사용하려면 **에이전트 스킬**(`.github/skills/<이름>/SKILL.md`)을 씁니다.

## 다 됐는지 확인

- [ ] `.github/prompts/story.prompt.md`에 머리말(`description`, `agent: ask`)과 `${selection}`이 있습니다.
- [ ] Session Target **Local** 새 채팅에서 `/story`를 실행했습니다.
- [ ] 선택한 문장이 스토리, 인수 조건, 확인 필요로 바뀌었습니다.
- [ ] 프롬프트 파일을 커밋하고 GitHub에 올렸습니다.
- [ ] Session Target을 다시 **Copilot**으로 돌려 두었습니다.

## 막히면

??? failure "/를 입력해도 story가 목록에 없습니다"
    1. Session Target이 **Local**인지 확인합니다. Copilot 하네스에서는 프롬프트 파일이 실행되지 않습니다.
    2. 파일 위치가 `.github/prompts/story.prompt.md`인지, 이름이 `.prompt.md`로 끝나는지 확인합니다.
    3. 파일을 저장했는지 확인하고 새 채팅을 엽니다.

??? failure "선택한 문장이 아니라 엉뚱한 내용으로 스토리를 만듭니다"
    `/story`를 실행하기 전에 편집기 선택이 풀린 경우입니다. 문서에서 문장을 다시 선택한 뒤, 편집기를 클릭하지 말고 바로 Chat 입력 칸에서 실행합니다.

??? failure "머리말이 글자로 그대로 보이거나 설명이 목록에 안 나옵니다"
    파일 첫 줄이 정확히 `---`인지 봅니다. 앞에 빈 줄이나 공백이 있으면 머리말로 인식되지 않습니다.

??? failure "Session Target에 Local이 보이지 않습니다"
    **+**(**New Chat**)를 먼저 눌러 새 채팅을 연 뒤 Session Target 컨트롤을 엽니다. 그래도 없으면 VS Code 버전(1.116 이상)을 확인하고 강사에게 화면을 보여 줍니다.
