# 실습 7-2. 내 업무 자동화 도구 만들기

!!! abstract "이 실습에서 할 일"
    - 총무팀이 매달 손으로 하는 집계를 Copilot으로 작은 프로그램으로 만듭니다.
    - 결과 숫자를 직접 대조하고, 테스트를 함께 받고, 보고용 요약까지 받습니다.
    - 같은 틀을 내 업무에 적용할 요청문으로 바꿔 가져갑니다.

**소요 시간** 약 14분  **실습 장소** 개인 리포지토리 `room-practice` (VS Code)  **관련 교안** [7교시 교안](index.md)

## 준비

- 7-1에 이어 개인 `room-practice`에서 합니다. 상태 표시줄 브랜치가 `main`인지 봅니다.
- 3-3에서 `/idea`로 검토한 결과가 있으면 다시 봅니다. 없어도 진행할 수 있습니다.

!!! warning "회사 자료는 넣지 않습니다"
    오늘은 가짜 데이터로 합니다. 개인 Pro 플랜에는 콘텐츠 제외 기능이 없습니다. 실제 업무 자료를 쓰기 전에 회사 보안 규칙을 먼저 확인합니다.

## STEP 1. 무엇을 자동화할지 읽기

1. `docs/04_월간집계_업무.md`를 엽니다.
2. "보고서에 필요한 것" 네 줄을 읽습니다.
3. `data/room_usage_2026-10.csv`를 열어 어떤 열이 있는지 봅니다.

확인: 입력(사용 기록), 처리(집계), 출력(보고서)을 한 문장씩 말할 수 있습니다.

## STEP 2. Agent로 만들기

1. Chat **+**(**New Chat**) → Session Target **Copilot**, Agent **Agent**를 고릅니다.
2. Chat에 붙여 넣기

    ```text
    docs/04_월간집계_업무.md의 "보고서에 필요한 것"을 만들어 주는 작은 프로그램을 만들어 주세요.
    - 파일: tools/monthly_report.py. 입력은 data/room_usage_2026-10.csv, 출력은 화면과 reports/monthly_2026-10.md
    - 표준 라이브러리만 쓰고, 설치는 하지 않습니다.
    - 끝 시간이 빈 행은 모든 계산에서 빼고, 뺀 행의 수를 보고서에 적습니다.
    - 사용 시간에서는 노쇼 행을 뺍니다. 건수에는 노쇼를 포함합니다.
    - 노쇼율은 노쇼 건수를 계산에 넣은 건수로 나누고 소수 첫째 자리까지 씁니다.
    - tests/test_monthly_report.py에 테스트를 추가합니다. 노쇼, 끝 시간이 빈 행, 부서 순위를 확인합니다. 실제 CSV가 아니라 작은 예시 데이터를 씁니다.
    - python tools/monthly_report.py 와 python -m pytest 를 실행해 결과를 보여 주세요.
    - 다른 파일은 바꾸지 마세요.
    ```

3. 승인 요청을 읽고 **Allow Once**를 누릅니다.

확인: `tools/monthly_report.py`와 `tests/test_monthly_report.py`가 생겼습니다.

## STEP 3. 숫자를 직접 대조하기

1. 터미널에서 실행합니다.

    === "Windows"

        ```bash
        python tools/monthly_report.py
        ```

    === "Mac"

        ```bash
        python3 tools/monthly_report.py
        ```

2. 아래 값과 비교합니다. 표 모양은 달라도 숫자가 같으면 됩니다.

    | 회의실 | 건수 | 사용 시간 | 노쇼 |
    |---|---|---|---|
    | 소회의실 A | 36 | 40.0시간 | 5 |
    | 소회의실 B | 21 | 24.5시간 | 3 |
    | 중회의실 | 46 | 46.0시간 | 8 |
    | 대회의실 | 15 | 16.0시간 | 3 |

    전체 118건, 노쇼 19건, 노쇼율 16.1%. 노쇼가 많은 부서는 영업팀 9건, 디자인팀 4건, 경영지원팀 3건. 뺀 행 2건.

3. 하나는 프로그램 없이 확인합니다. CSV를 열고 찾기(Windows `Ctrl+F`, Mac `⌘F`)에 `,R4,`를 입력합니다. 16건이 찾아집니다. 끝 시간이 빈 R4 행 1건을 빼면 대회의실 15건과 같습니다.

확인: 숫자가 같습니다. 다르면 어느 규칙이 다른지 Chat에 알려 고칩니다.

## STEP 4. 테스트 읽고 실행하기

1. `tests/test_monthly_report.py`를 열어 `assert`가 STEP 2의 규칙과 같은지 읽습니다.
2. 터미널에서 실행합니다.

    === "Windows"

        ```bash
        python -m pytest
        ```

    === "Mac"

        ```bash
        python3 -m pytest
        ```

확인: `failed`가 없습니다. 테스트를 지워서 통과시킨 것은 아닌지 봅니다.

## STEP 5. 보고용 요약 받기

1. Chat **+**(**New Chat**) → Agent **Ask**를 고릅니다.
2. 탐색기에서 `reports/monthly_2026-10.md`를 Chat 입력 칸에 끌어다 놓습니다.
3. Chat에 붙여 넣기

    ```text
    첨부한 보고서를 총무팀장에게 보고할 세 줄로 요약해 주세요. 보고서에 있는 숫자만 씁니다. 원인을 추측하면 "추측"이라고 표시해 주세요.
    ```

확인: 요약의 숫자가 보고서와 같고, 보고서에 없는 원인을 사실처럼 쓰지 않았습니다.

## STEP 6. 커밋하기

1. 소스 제어를 엽니다. Changes에 `tools/monthly_report.py`와 `tests/test_monthly_report.py`가 있는지 봅니다. `reports/`는 `.gitignore`에 있어 보이지 않습니다.
2. 메시지 칸의 반짝이 아이콘(**Generate Commit Message**)을 눌러 초안을 받고, 읽어 보고 고칩니다.
3. **Commit**, **Sync Changes**를 누릅니다.

확인: github.com의 `room-practice`에서 `tools/monthly_report.py`가 보입니다.

## STEP 7. 내 업무로 바꾸기

내 업무에서 반복하는 일 하나를 떠올려 아래 틀을 채웁니다. 실행하지 않아도 됩니다. 메모장에 저장해 가져갑니다.

```text
[일] 내가 매번 손으로 하는 일:
[입력] 어떤 파일을 받는가 (열 이름, 예시 몇 줄. 실제 값 대신 가짜 값으로):
[처리] 어떤 규칙으로 계산하는가 (빼는 경우 포함):
[출력] 어떤 모양으로 받고 싶은가:
[검증] 손으로 계산해 맞춰 볼 숫자 하나:
```

확인: 틀의 다섯 줄을 채웠습니다.

!!! tip "같은 방법으로 시킬 수 있는 일"
    다섯 줄 틀은 보고서 말고도 씁니다. GH-300 시험의 생산성 영역에 나오는 예입니다.

    | 하고 싶은 일 | 요청 예 |
    |---|---|
    | 샘플 데이터 만들기 | "이 열 이름으로 테스트용 가짜 데이터 30행을 CSV로 만들어 줘. 끝 시간이 빈 행 2개 포함" |
    | 오래된 코드 현대화 | "이 함수를 지금 Python 방식(타입 힌트, pathlib)으로 바꿔 줘. 동작은 그대로, 테스트로 확인" |
    | 통합 테스트 | "CSV 읽기부터 보고서 파일 저장까지 한 번에 확인하는 테스트를 만들어 줘" |
    | 성능 개선 | "10만 행이면 느릴 곳을 찾아 이유와 함께 고칠 방법을 제안해 줘. 바꾸기 전에 먼저 보여 줘" |

## 다 됐는지 확인

- [ ] `tools/monthly_report.py`를 Agent로 만들었다
- [ ] 결과 숫자를 표와 대조하고, `,R4,`를 직접 세어 확인했다
- [ ] 테스트의 `assert`를 읽고 실행했다
- [ ] 보고서로 세 줄 요약을 받고 숫자를 대조했다
- [ ] 내 업무의 다섯 줄 틀을 채웠다

## 막히면

!!! tip "먼저 Copilot과 함께 해결합니다"
    오류 메시지나 막힌 상황을 Chat(Ask)에 붙여 넣고 원인과 해결 순서를 묻습니다. 아래는 자주 막히는 경우입니다. 묻는 방법은 [막혔을 때](../setup/3-troubleshooting.md#copilot)에 있습니다.

??? failure "숫자가 표와 달라요"
    끝 시간이 빈 행을 뺐는지, 노쇼를 사용 시간에서만 뺐는지, 노쇼율의 분모가 118인지 봅니다. 다른 규칙을 Chat에 그대로 적어 고치게 합니다.

??? failure "pandas 설치를 하겠다고 해요"
    승인하지 않습니다. "표준 라이브러리 csv 모듈만 쓰세요"라고 요청합니다.

??? failure "테스트에서 tools를 찾지 못해요"
    명령을 `room-practice` 폴더에서 실행했는지 봅니다. 실패 메시지를 Chat에 붙여 고치게 합니다.

??? failure "room_usage_2026-10.csv가 없어요"
    파일이 추가되기 전에 템플릿으로 만든 리포지토리입니다. github.com의 `skilleat-labs/meeting-room-starter`에서 `data/room_usage_2026-10.csv`와 `docs/04_월간집계_업무.md`를 열고 **Raw** 내용을 같은 위치에 새 파일로 저장합니다.
