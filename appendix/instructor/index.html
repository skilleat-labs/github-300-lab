    강사용 진행 메모¶

    수강생에게는 이 페이지를 따로 안내하지 않습니다. 수업 준비와 진행 중 판단에 씁니다.

    수업 전 준비¶

    1. 템플릿 리포지토리 만들기¶

    1. skilleat-labs 조직에 리포지토리 meeting-room-starter를 Public으로 만듭니다.
    2. 가이드 소스의 starter/ 폴더 내용을 폴더째가 아니라 내용만 리포지토리 루트에 올립니다. 숨김 파일 .github/, .vscode/, .gitignore가 빠지지 않았는지 확인합니다.
    3. Settings → General → Template repository를 체크합니다.
    4. Actions 탭에서 테스트가 초록인지 봅니다.

    확인: https://github.com/skilleat-labs/meeting-room-starter에 Use this template 버튼이 보이고, python -m pytest가 4 passed입니다.

    solutions/는 올리지 않습니다

    solutions/는 강사 참고 정답입니다. 템플릿에 들어가면 수강생이 Copilot 없이 답을 보게 됩니다.

    2. 다른 계정으로 리허설¶

    수강생과 같은 조건(Copilot Pro, 새 계정)의 테스트 계정으로 1-2부터 끝까지 한 번 해 봅니다.

    • 1-2 템플릿 → room-practice → VS Code Clone → 4 passed
    • 2-3 18시 버그 → 4-1~4-3 겹침, PR, CI 초록
    • 4-4 팀 리포지토리, Collaborators 초대, Pages Source GitHub Actions
    • 6-1 Copilot 코드 리뷰 요청이 Reviewers에 보이는지
    • 6-2 Copilot이 만든 pages.yml로 실제 배포
    • 5-3 이슈 Assignees에 Copilot이 보이는지, 7교시까지 PR이 열리는지
    • 3-3 /idea, 7-2 월간 보고서 숫자가 가이드의 표와 같은지

    화면 이름이 FACTS의 "(검색 요약)" 항목(PR Summary, 코드 리뷰 Request, 클라우드 에이전트 Assignees, GitHub MCP)과 다르면 가이드를 고칩니다.

    3. 수강생 사전 안내¶

    • 설치 3개: VS Code(1.116 이상, Copilot Chat 내장), Git, Python 3.12 이상. 설치할 것
    • 개인 GitHub 계정에 Copilot Pro 라이선스가 활성인지 확인합니다. github.com 개인 설정 → Billing & licensing 또는 Copilot 설정에서 봅니다.
    • 회사 PC라면 방화벽 허용 주소와 프록시를 미리 확인합니다. 막혔을 때

    Pro 지급 방식 사전 확인

    Copilot Pro 신규 가입이 2026-04에 일시 중단된 적이 있습니다. 회사가 라이선스를 어떤 방식으로 지급하는지(개인 결제 후 정산, 조직 지급 등) 교육 담당자와 미리 확인합니다. 라이선스가 없는 계정은 Copilot Free가 되어 PR Summary, 클라우드 에이전트를 쓸 수 없습니다.

    수강 전 설문 반영¶

    처음 쓰는 사람이 많고, 기능 개발과 업무 자동화 수요가 큽니다. 리팩터링 수요는 없습니다.

    설문에서 나온 요구 어디서
    Copilot과 VS Code 기본 사용법 1교시 VS Code 화면, 1-2 STEP 9, STEP 7(모르는 명령 묻기), 한 장 정리, 2교시
    업무용 프로그램, 기능 개발 4교시, 5-2
    아이디어 검토, 업무 자동화 도구 3-3 /idea, 7-2
    테스트 코드, 품질 검증 4-2 /tests, 5-3, 7-2
    팀 활용 사례 공유 7-3 docs/활용사례.md, 정리 시간 공유
    코드 설명, 주석, 기술 문서 2-2 /explain, /doc, 5-3 README
    데이터 처리, 분석 7-2 CSV 집계와 요약

    교시별 주의할 점¶

    교시 자주 막히는 곳 대처
    1 회사 프록시, 로그인 계정 혼동, Mac python python3 안내, 계정 메뉴에서 로그인 계정 확인
    2 Agent가 data/ 파일까지 바꿈 Discard Changes 습관을 이때 잡아 둡니다
    3 /idea가 안 뜸 .github/skills/idea/SKILL.md 위치, name: idea가 폴더 이름과 같은지, 저장 후 새 채팅인지
    4 /plan이 Copilot 하네스가 아닌 채팅에서 실행됨, 승인을 읽지 않고 누름 새 채팅 + Session Target 확인. 승인 내용을 소리 내어 읽게 합니다
    4-4 팀원 초대 수락 지연 초대 주소 /invitations를 화면에 띄워 둡니다
    5 역할이 개발자가 아니라고 구현을 미룸 "모두 하나씩"을 다시 강조. S1, S4는 오전에 해 본 사람에게
    6-1 충돌 한 팀 화면을 공유해 같이 풀어 줍니다. 두 검사가 모두 남았는지, 테스트 수가 합쳐졌는지
    6-2 Pages Source 미설정, 권한 누락 4-4에서 Source를 바꿨는지 확인. contents: read, pages: write, id-token: write, environment: github-pages
    7-1 알림창을 실제 서비스에서 해 보려는 수강생 개인 실습 리포지토리에서만 한다고 분명히 말합니다
    5-3 에이전트 작업이 7교시까지 안 끝남 PR 상태만 보고 넘어갑니다. 수업 내 필수 완료 조건이 아닙니다. 끝나면 변경 읽기 → Approve and run workflows → Ready for review → 승인(맡긴 사람 제외) → 병합
    7-2 실제 회사 자료를 넣으려는 수강생 가짜 데이터로 하게 합니다. 개인 Pro에는 콘텐츠 제외가 없습니다

    크레딧 운영¶

    Pro는 월 1,500크레딧입니다. 하루 과정에서 바닥나지 않게 아래를 지킵니다.

    • 모델은 Copilot Fusion(Standard): 모델 선택기에 Auto는 없고 Copilot Fusion이 맨 위에 있습니다. 2026-11-30까지 모델 비용 30% 할인. 1-1에서 설정하게 합니다.
    • Copilot 코드 리뷰는 1인 1회: 1회 약 150크레딧(Balanced 기준, 평균 약 1.50달러). 6-1에서 각자 자기 PR에만.
    • 클라우드 에이전트는 팀당 1회: 5-3에서 PM만.
    • 인라인 제안과 NES는 크레딧을 쓰지 않습니다. Chat, 에이전트, 코드 리뷰, 클라우드 에이전트가 씁니다.
    • 사용량은 VS Code 상태 표시줄의 Copilot status dashboard에서 봅니다.
    • 소진 시: 그 수강생은 짝의 화면을 같이 보며 검토 역할을 맡깁니다. 다음 달 초기화 전까지 추가 예산 설정은 회사 정책에 따릅니다.

    미션 5-1 강사 답변 (현업 역할)¶

    PO가 "결정하지 못한 것"을 물으러 오면 총무팀 최수연 대리처럼 답합니다. 미리 수강생 화면에 띄우지 않습니다.

    질문 강사 답
    한 번에 예약할 수 있는 최대 시간 최대 4시간으로 합니다. 임원 회의가 반나절입니다. (이번 백로그 S1~S4에는 넣지 않습니다. 다음 범위)
    노쇼 자동 취소 이번 범위가 아닙니다. 누가 왔는지 알 방법이 없습니다.
    현황판 연락처 공개 지금은 결정하지 않습니다. 나중에 변경 요청(CR)으로 드리겠습니다.

    답을 바로 주지 말고 되물어도 좋습니다

    "Copilot은 뭐라고 추천했나요? 근거는요?"라고 되물으면 PO가 Copilot의 결정안을 검토했는지 확인할 수 있습니다. 최대 4시간을 구현하자는 팀에는 "이번 MVP가 아니니 이슈만 남기세요"라고 답합니다.

    CR-001 발표 타이밍¶

    6교시 미션 6-2가 끝난 뒤(팀 현황판이 웹 주소로 열린 뒤) 발표합니다. 현황판이 공개 주소로 열리고, 거기에 연락처가 보이는 것을 확인한 직후가 효과가 큽니다.

    발표 문구(그대로 읽습니다):

    CR-001

    현황판이 회의실 앞 태블릿과 사외에서도 보입니다. 연락처는 빼고, 예약자는 성과 '○○'로만 보여 주세요. 예: 김○○

    5-1에서 "연락처는 CR로 나중에"라고 답했던 것과 이어진다고 말해 줍니다.

    • XSS: html.escape()로 제목, 예약자, 팀(연락처를 남긴 경우 연락처도).
