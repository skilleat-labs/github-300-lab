    명령 한눈에 보기¶

    명령 하는 일
    python -m pytest 테스트 실행 (처음엔 4 passed)
    python -m booking rooms 회의실 목록
    python -m booking list --date 2026-11-10 그 날짜 예약 목록
    python -m booking add --room R1 --title 회의 --date 2026-11-10 --start 10:00 --end 11:00 --booker 홍길동 --attendees 2 예약하기. data/reservations.json이 바뀝니다
    python -m booking report 회의실 이용률 보고서
    python build_site.py 현황판 site/index.html 만들기

    데이터 되돌리기

    add로 바뀐 data/reservations.json은 VS Code 소스 제어에서 Discard Changes로 되돌립니다. 명령은 가상환경 (.venv)을 켠 터미널에서 실행합니다. 그러면 Mac도 python으로 됩니다.

    booking/rules.py¶

    예약 검사 규칙입니다. 2교시 18시 버그(S4), 4교시 겹침 검사(S1), 5교시 정원 검사(S2)가 모두 이 파일의 validate()에서 일어납니다. TODO 주석과 end >= 비교를 찾아보세요.

    from __future__ import annotations

from datetime import datetime

from .models import Room, Reservation

OPEN_TIME = "09:00"
CLOSE_TIME = "18:00"


def to_minutes(hhmm: str) -> int:
    t = datetime.strptime(hhmm, "%H:%M")
    return t.hour * 60 + t.minute


def validate(new: Reservation, rooms: list[Room], existing: list[Reservation]) -> list[str]:
    """새 예약에 문제가 있으면 오류 메시지 목록을 돌려준다. 문제가 없으면 빈 목록."""
    errors = []

    room_ids = [r.id for r in rooms]
    if new.room_id not in room_ids:
        errors.append(f"없는 회의실입니다: {new.room_id}")

    start = to_minutes(new.start)
    end = to_minutes(new.end)
    if start >= end:
        errors.append("끝나는 시간은 시작 시간보다 늦어야 합니다.")

    if start < to_minutes(OPEN_TIME) or end >= to_minutes(CLOSE_TIME):
        errors.append(f"운영 시간({OPEN_TIME}~{CLOSE_TIME}) 밖입니다.")

    if start % 30 != 0 or end % 30 != 0:
        errors.append("예약은 30분 단위로만 할 수 있습니다.")

    # TODO: 같은 회의실, 같은 날짜에 시간이 겹치는 예약은 막아야 한다 (현업 요청 1번)

    return errors

    booking/service.py¶

    예약하기와 목록 보기입니다. 취소(cancel)는 아직 없습니다. 5교시 S3에서 추가합니다.

    from __future__ import annotations

from .models import Reservation
from .rules import validate
from .store import load_rooms, load_reservations, save_reservations, next_id


def reserve(room_id, title, date, start, end, booker, attendees, team="", phone=""):
    rooms = load_rooms()
    reservations = load_reservations()
    new = Reservation(
        id=next_id(reservations), room_id=room_id, title=title, booker=booker, team=team,
        phone=phone, date=date, start=start, end=end, attendees=attendees,
    )
    errors = validate(new, rooms, reservations)
    if errors:
        return None, errors
    reservations.append(new)
    save_reservations(reservations)
    return new, []


def list_reservations(date=None):
    reservations = load_reservations()
    if date:
        reservations = [r for r in reservations if r.date == date]
    return sorted(reservations, key=lambda r: (r.date, r.start, r.room_id))

    build_site.py¶

    예약 현황판을 만드는 스크립트입니다. 제목과 예약자를 그대로 HTML에 넣고(7-1 XSS), 연락처를 그대로 보여 줍니다(6-3 CR-001).

    """예약 데이터로 예약 현황판 웹페이지(site/index.html)를 만든다."""
from pathlib import Path

from booking.store import load_rooms, load_reservations

OUT = Path(__file__).resolve().parent / "site" / "index.html"


def build():
    rooms = {r.id: r for r in load_rooms()}
    reservations = sorted(load_reservations(), key=lambda r: (r.date, r.start, r.room_id))

    rows = ""
    for r in reservations:
        room = rooms.get(r.room_id)
        room_name = room.name if room else r.room_id
        rows += f"""
        <tr>
          <td>{r.date}</td><td>{r.start}~{r.end}</td><td>{room_name}</td>
          <td>{r.title}</td><td>{r.booker} ({r.team})</td><td>{r.phone}</td><td>{r.attendees}명</td>
        </tr>"""

    html = f"""<!doctype html>
<html lang="ko">
<head>
<meta charset="utf-8">
<meta name="viewport" content="width=device-width, initial-scale=1">
<title>회의실 예약 현황</title>
<style>
  body {{ font-family: "Apple SD Gothic Neo", "Malgun Gothic", sans-serif; margin: 32px; color: #1a1a1a; }}
  h1 {{ font-size: 24px; }}
  table {{ border-collapse: collapse; width: 100%; }}
  th, td {{ border-bottom: 1px solid #ddd; padding: 8px 10px; text-align: left; }}
  th {{ background: #f5c43d; }}
</style>
</head>
<body>
<h1>회의실 예약 현황</h1>
<p>예약 {len(reservations)}건</p>
<table>
  <tr><th>날짜</th><th>시간</th><th>회의실</th><th>회의</th><th>예약자</th><th>연락처</th><th>인원</th></tr>{rows}
</table>
</body>
</html>
"""
    OUT.parent.mkdir(parents=True, exist_ok=True)
    OUT.write_text(html, encoding="utf-8")
    print(f"[완료] {OUT.relative_to(Path.cwd()) if OUT.is_relative_to(Path.cwd()) else OUT} 에 예약 {len(reservations)}건을 썼습니다.")


if __name__ == "__main__":
    build()

    .github/workflows/ci.yml¶

    자동 테스트 워크플로 "테스트"입니다. PR을 열거나 main에 push하면 Python 3.12로 테스트를 실행합니다.

    name: 테스트

on:
  pull_request:
  push:
    branches: [main]

jobs:
  test:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-python@v5
        with:
          python-version: "3.12"
      - run: pip install -r requirements-dev.txt
      - run: python -m pytest -v

    docs/01_킥오프_회의록.md¶

    5교시 PO, BA가 근거로 쓰는 회의록입니다. "결정하지 못한 것" 3개를 Copilot이 마음대로 정하지 않는지 확인합니다.

    # 회의실 예약 서비스 킥오프 회의록

- 일시: 2026-10-29 (수) 14:00~15:00
- 참석: 최수연(총무팀), 강도윤(총무팀 팀장), 한지민(IT기획팀), 오세훈(서비스개발팀)

## 논의 내용

- 최수연: 제일 급한 건 겹치는 예약이에요. 그거부터 막아 주세요.
- 오세훈: 지금 예약 데이터에 겹침 검사가 없어서 바로 넣을 수 있을 것 같습니다.
- 강도윤: 한 번에 너무 오래 잡는 것도 문제예요. 최대 2시간으로 막읍시다.
- 최수연: 임원 회의는 반나절씩 하는데요. 최대 4시간은 돼야 해요.
- 한지민: 그건 정책이라 총무팀 안에서 정리해서 알려 주세요.
- 강도윤: 노쇼는 시작하고 10분 안에 아무도 안 오면 자동으로 취소되게 하면 어떨까요.
- 최수연: 10분은 짧아요. 15분은 줘야 할 것 같아요.
- 오세훈: 자동 취소는 회의실에 누가 왔는지 알아야 해서 이번 범위에서는 어렵습니다.
- 한지민: 현황판 웹페이지에는 누가 예약했는지 보이면 좋겠다는 의견이 많았습니다. 연락처도 같이요.
- 강도윤: 현황판이 외부에서도 보이는 건가요? 그건 좀 확인해 봐야겠네요.

## 결정한 것

1. 겹치는 예약을 막는다.
2. 정원을 넘는 예약을 막는다.
3. 예약 현황판 웹페이지를 만든다.
4. 예약 취소 기능을 만든다.

## 결정하지 못한 것

- 한 번에 예약할 수 있는 최대 시간 (2시간 vs 4시간)
- 노쇼 자동 취소 기준 시간 (10분 vs 15분), 그리고 이번 범위에 넣을지
- 현황판에 연락처를 보여 줄지

## 이번 범위가 아닌 것

- 사내 메신저 알림 연동
- 로그인 (지금은 예약자 이름을 직접 적는다)
