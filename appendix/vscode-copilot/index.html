    VS Code와 Copilot 한 장 정리¶

    처음 쓰는 분을 위한 정리입니다. 수업 중에 막히면 이 페이지를 먼저 봅니다.

    VS Code 화면¶

    이름 어디에 하는 일
    Activity Bar (활동 막대) 맨 왼쪽 아이콘 줄 탐색기, 소스 제어 같은 보기 바꾸기
    Primary Side Bar (기본 사이드바) 왼쪽 탐색기(파일 목록), 소스 제어
    Editor (편집기) 가운데 파일을 읽고 고치기
    Secondary Side Bar (보조 사이드바) 오른쪽 기본으로 Chat 보기가 있는 곳
    Panel (패널) 아래 터미널, 문제(Problems), 출력
    Status Bar (상태 표시줄) 맨 아래 줄 브랜치 이름, Copilot 아이콘

    자주 쓰는 단축키¶

    하는 일 Mac Windows
    명령 팔레트 (모든 명령 찾기) ⇧⌘P Ctrl+Shift+P
    파일 이름으로 열기 (Quick Open) ⌘P Ctrl+P
    왼쪽 사이드바 열고 닫기 ⌘B Ctrl+B
    터미널 열기 ⌃` Ctrl+`
    소스 제어 보기 ⌃⇧G Ctrl+Shift+G
    바뀐 줄 바로 보기 (diff) 줄 번호 옆 색 막대 클릭 줄 번호 옆 색 막대 클릭
    저장 ⌘S Ctrl+S
    Chat 보기 ⌃⌘I Ctrl+Alt+I
    새 채팅 ⌘N (Chat 보기에서) Ctrl+N (Chat 보기에서)
    인라인 채팅 (편집기, 터미널) ⌘I Ctrl+I
    제안 수락 / 거절 Tab / Esc Tab / Esc

    저장을 자주 잊는다면 File → Auto Save를 켭니다.

    단축키가 안 먹으면

    • Mac은 ⌘(Command)와 ⌃(Control)를 구분합니다. 소스 제어는 ⌃입니다.
    • 한/영이 한글이면 영문으로 바꿉니다.
    • 다른 확장이 같은 키를 쓰는 경우입니다. 명령 팔레트에서 Preferences: Open Keyboard Shortcuts를 열고, 검색 칸의 키보드 아이콘(Record Keys)을 누른 뒤 그 키를 눌러 연결된 명령을 봅니다.
    • 급하면 단축키 대신 왼쪽 활동 막대의 아이콘을 누릅니다.

    소스 제어 보기¶

    왼쪽 활동 막대의 가지 모양 아이콘입니다. Copilot이 고친 파일도 여기에 나타납니다.

    부분 어디에 하는 일 같은 Git 명령
    메시지 입력 칸 맨 위 커밋에 남길 한 줄 설명. 반짝이 아이콘으로 Copilot 초안 받기
    Commit 버튼 입력 칸 아래 바뀐 것을 기록으로 남기기. 커밋한 뒤에는 Sync Changes로 바뀜 git add + git commit
    Changes 버튼 아래 목록 커밋하지 않은 변경 파일. 내가 고친 것도, Copilot이 고친 것도 여기 보임 git status
    파일 클릭 Changes 목록 바뀌기 전과 후를 비교(diff) git diff
    Discard Changes (굽은 화살표) 파일에 마우스를 올리면 그 파일을 마지막 커밋 상태로 되돌리기 git restore
    Sync Changes 커밋한 뒤 버튼 자리 GitHub의 새 커밋 받고 내 커밋 올리기 git pull + git push
    그래프 맨 아래 커밋 기록. main과 구름 표시가 같은 줄이면 GitHub와 같은 상태 git log

    VS Code 버튼과 Git 명령¶

    오늘은 Git 명령을 직접 치지 않고 VS Code 버튼으로 합니다. 버튼마다 같은 일을 하는 Git 명령이 있습니다. 1교시에 배운 clone, push, pull이 어느 버튼인지 연결해 봅니다.

    VS Code에서 누르는 것 같은 Git 명령 하는 일 오늘 처음 쓰는 곳
    명령 팔레트 Git: Clone git clone GitHub 리포지토리를 내 PC로 처음 가져오기 1-2
    Changes 목록에서 파일 클릭 git diff 바뀌기 전과 후 비교 1-3, 2-3
    Discard Changes git restore 커밋하지 않은 변경을 마지막 커밋 상태로 되돌리기 1-3
    메시지 입력 후 Commit git add + git commit 바뀐 것을 기록으로 남기기 2-3
    Sync Changes git pull + git push GitHub의 새 커밋 받고, 내 커밋 올리기 2-3
    자동 확인 (git fetch 정기 실행) git fetch GitHub에 새 커밋이 있는지 확인만 하기 2-3
    상태 표시줄 브랜치 이름 → Create new branch... git switch -c 새 브랜치 만들고 옮겨 가기 4-1
    Publish Branch git push -u origin 브랜치 새 브랜치를 GitHub에 처음 올리기 4-3
    상태 표시줄 브랜치 이름 → 다른 브랜치 고르기 git switch 다른 브랜치로 옮겨 가기 4-3

    VS Code 곳곳에서 Copilot 부르기¶

    어디서 어떻게 무엇을
    편집기 쓰는 중 회색 글자 인라인 제안, 다음 편집 제안
    편집기 ⌘I / Ctrl+I 선택한 부분만 묻거나 고치기
    편집기 오른쪽 클릭 → Explain 선택한 코드 설명
    편집기 오른쪽 클릭 → Generate Code → Generate Docs, Generate Tests 설명 주석, 테스트 만들기
    터미널 ⌘I / Ctrl+I 터미널에서 묻기. 모르는 명령의 뜻 묻기 (1-2)
    터미널 실패한 명령 옆 반짝이 아이콘 오류 설명과 고치는 방법
    소스 제어 메시지 칸의 반짝이 아이콘 (Generate Commit Message) 커밋 메시지 초안
    Chat 보기 ⌃⌘I / Ctrl+Alt+I Ask(묻기), Agent(고치기). 계획은 /plan

    Chat에 맥락 붙이기¶

    방법 쓰는 법
    +(Add Context) 파일, 폴더, 심볼, 이슈, PR 고르기
    끌어다 놓기 탐색기의 파일을 입력 칸에 놓기
    #파일이름 입력 칸에 #와 파일 이름 일부를 치고 ↑ ↓, Enter로 고르면 파일이 붙습니다. 마우스 없이 첨부할 수 있습니다
    # 입력 칸에 #를 치면 쓸 수 있는 맥락 목록이 나옵니다. #codebase, 선택한 글을 뜻하는 #selection이 대표적입니다
    코드 선택 코드를 선택한 채로 묻기

    # 목록은 하네스와 확장에 따라 다릅니다. 외우지 말고 목록에서 고릅니다.

    어떤 방법을 쓸까¶

    하고 싶은 일 쓰는 것
    코드나 문장을 이어 쓰기 인라인 제안
    이 줄만 묻기, 이 부분만 고치기 인라인 채팅
    코드나 문서를 이해하기, 비교하기 Chat Ask
    업무 아이디어 검토하기 Chat Ask, /idea (3-3)
    여러 파일을 고치고 실행까지 맡기기 Chat Agent
    큰 작업의 계획부터 받기 /plan (선택기에 없고 입력 칸에 명령으로)
    내가 없는 동안 맡기기 클라우드 에이전트 (5-3)
